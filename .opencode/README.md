# .opencode

OpenCode и Claude Code работают от одних и тех же файлов правил, копий нет.

OpenCode читает `AGENTS.md` в корне, а через `opencode.json` ему дополнительно
подкладываются те же файлы, что читает Claude Code. Поэтому обновлять правила нужно
ровно в одном месте: в `CLAUDE.md` и `Agents/*.md` приватного репозитория `College`.

Эта папка существует, чтобы было понятно, где искать настройки, и чтобы OpenCode не
создал её сам с пустым содержимым.
