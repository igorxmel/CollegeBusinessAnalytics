# Правила для агентов

Единый источник правил для этого репозитория лежит в приватном репозитории `College`,
который подключает курсы подмодулями:

- `CLAUDE.md` в корне `College` — общие правила для всех курсов;
- `Agents/CollegeBusinessAnalytics.md` — специфика именно этого курса.

Здесь эти правила намеренно не продублированы. Копия разъехалась бы с оригиналом, а
внутренние заметки не должны попадать в публичный репозиторий.

Если ты открыл этот репозиторий отдельно и `College` рядом нет, работай по тому, что
видишь в коде: генераторы отчётов лежат в `.claude/tools`, разборы заданий в `README.md`
внутри папок работ.
