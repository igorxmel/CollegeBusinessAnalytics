# College Business Analytics

Практические работы по бизнес-аналитике. Здесь лежат мои решения.

Каждое задание живёт в отдельной папке. Внутри исходная методичка `Task.pdf` и папка
`Solution` с отчётом.

## Задания

- [Task 1. Сценарий глубинного интервью](Task%201st%20Deep%20Interview%20Guide)
  Гайд для интервью с заказчиком интернет-магазина кроссовок: восемь обязательных блоков
  вопросов от бизнес-требований до пользовательских историй, тайминг беседы и шаблон
  протокола.

- [Task 2. Кейс глубинного интервью](Task%202nd%20Deep%20Interview%20Case)
  Кейс интервью с заказчиком в формате «вопрос/ответ», составленный по гайду из первой
  работы: приветствие и договорённости, сорок один вопрос по восьми блокам и завершение
  с резюмированием.
